# Merged Dataset & Compatibility Report
This report was generated by the dataset merge pipeline in **SIMULATION MODE** because the recommended public datasets are not downloaded locally.
## 1. Compatibility Report
### A. Classification Dataset Compatibility (Kaggle Brain MRI 4-Class vs Deployed)
- **Label Compatibility:** **100% Compatible.** Both datasets contain identical categories: Glioma, Meningioma, Pituitary, and No Tumor (healthy).
- **Resolution Compatibility:** **Fully Compatible.** The deployed EfficientNet-B0 backbone resizes all inputs to 224x224. Images are resized dynamically during loading.
- **Folder Structure Alignment:** **Fully Compatible.** Subfolders will be standardized to uppercase names: `/Glioma`, `/Meningioma`, `/Pituitary`, and `/No Tumor` across all splits.
- **Integration Cost:** **Negligible.** Direct image copying with MD5 checks to bypass overlaps.
### B. Segmentation Dataset Compatibility (BraTS 2021 vs Deployed LGG)
- **Label Compatibility:** **Compatible via clustering.** BraTS 2021 uses multi-class labels (0: BG, 1: Necrosis, 2: Edema, 4: Enhancing). These will be logically grouped `(1 | 2 | 4) -> 255` (binary tumor foreground) to match the deployed binary UNeXt pipeline.
- **Dimensionality & Format Mismatch:** **Requires Preprocessing.** BraTS is stored as 3D NIfTI volumes (`.nii.gz`), while the deployed app uses 2D TIF slices (`.tif`). Slices must be extracted along the axial plane and saved as 2D TIFs.
- **Resolution Compatibility:** **Fully Compatible.** extracted slices will be resized to 256x256 to fit the UNeXt input shape.

## 3. Merging Rules & Pipeline Execution Logic
1. **De-duplication:** Calculates the MD5 hash of every classification and segmentation image. If an incoming image from the recommended dataset matches an existing image's hash, it is discarded.
2. **Segmentation Slicing:** Loads BraTS `.nii.gz` volumes, loops over the axial slices, extracts slice-mask pairs where tumor pixels > 100, resizes them to 256x256, Z-score normalizes them, and saves them as `brats_slice_*.tif`.
3. **Folder Structure:** Retains `/images` and `/masks/0` directories for UNeXt, and `/train`, `/valid`, `/test` with subfolders for classification.
